# Clip Finder V12

Version autonome, sans Klap.

Nouveautés V12 :
- détection de plusieurs visages ;
- suivi léger des visages dans le temps ;
- changement automatique du cadrage vertical toutes les ~2 secondes ;
- estimation locale du visage/interlocuteur actif par activité visuelle + visibilité ;
- sous-titres faster-whisper ;
- export MP4 1080x1920 ;
- Ollama reste optionnel pour la sélection des meilleurs passages.

Limites :
- ce n'est pas de l'identification biométrique ;
- le changement de locuteur est une estimation visuelle, pas une diarisation audio parfaite ;
- aucun contournement DRM, paywall ou anti-bot ;
- Render Free peut être lent.
